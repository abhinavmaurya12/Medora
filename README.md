# 🧬 MEDORA — The Future of Medical Learning

**Your Interactive Biology Textbook & NEET Preparation Companion**

Medora is a modern, interactive learning platform designed for students preparing for NEET and studying NCERT Biology. It brings chapter-wise learning, audio reading, progress tracking, quizzes, previous-year question practice and mock tests together in one place.

🌐 **Live Website:** https://abhinavmaurya12.github.io/Medora/

📂 **GitHub Repository:** https://github.com/abhinavmaurya12/Medora

---

## ✨ Features

### 📚 Interactive Biology Learning
- NCERT-aligned Biology learning material.
- Class 11th and Class 12th Biology sections.
- Chapter-wise reading experience.
- Search chapters and individual topics.
- Navigate between previous and next chapters.
- Save chapters for quick access.
- Track your reading progress.

### 🎧 Listen-Along Reader
- Listen to chapter content using text-to-speech.
- Play, pause and stop reading.
- Adjust reading speed.
- Select available voice options.
- Change text size for comfortable reading.

### 📝 Biology Quiz
- Chapter-wise MCQ practice.
- Class 11th and Class 12th quizzes.
- Mixed practice quizzes.
- **32 chapter quizzes with 1,344 questions.**

### 🎯 NEET UG Previous Year Question Practice
- Practice NEET-style questions.
- Botany, Zoology, Physics and Chemistry sections.
- Full-test, subject-wise and batch-wise practice.
- **21 batch sets containing 1,050 questions.**

### 🏆 NEET Mock Tests
- 7 full-length mock tests.
- 180 questions per test.
- 3-hour examination format.
- +4 / −1 marking scheme.
- Subject-wise performance report.

### 💾 Personal Study Tools
- Save chapters and bookmarks.
- Highlights and personal notes.
- Backup and restore study data.
- Save or print study material as PDF.
- Daily study goal and progress tracking.
- Personal profile saved on your device.

### 🌙 User Experience
- Light and dark themes.
- Responsive interface.
- Keyboard shortcuts.
- Focus reading mode.
- Search topics quickly.
- Offline support and installable app experience.

## 🛠️ Technology

Medora is built as a lightweight web application using:

- **HTML5** — Page structure and content.
- **CSS3** — Styling and responsive design.
- **JavaScript** — Application functionality and interactions.
- **Web Speech API** — Read-aloud experience.
- **Progressive Web App (PWA)** — Installable app experience.
- **Service Worker** — Offline support and caching.
- **JSON** — Application configuration and data.

## 📲 How to Use

1. Open the [Medora website](https://abhinavmaurya12.github.io/Medora/).
2. Enter your name to personalize your study experience.
3. Choose Class 11th or Class 12th Biology.
4. Select a chapter and start reading.
5. Use the listen-along reader to hear the content.
6. Practice chapter quizzes and NEET UG questions.
7. Attempt mock tests to evaluate your preparation.
8. Track your progress and save your study notes.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `/` | Search topics |
| `Ctrl + K` | Open or close command palette |
| `T` | Switch light/dark theme |
| `← / →` | Previous / next chapter |
| `F` | Toggle focus reading mode |
| `Esc` | Close menu or dialog |
| `1–4` or `A–D` | Select quiz answer |
| `Enter` or `→` | Next quiz question |

## 🎯 Project Goal

The goal of Medora is to make Biology learning more interactive, accessible and organized. Instead of switching between textbooks, question banks and separate study tools, students can use one platform to read, listen, practice and monitor their learning progress.

**Learn smarter. Practice consistently. Prepare confidently.**
